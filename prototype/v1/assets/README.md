# 網站共用視覺素材

本目錄五張 PNG 原樣複製自 `streamlit_cloud/assets/`，不重新設計圖示或覆寫網站原圖。

- ocean_watercolor_chibi_background.png：網站海洋水彩背景。由 website-theme.css 以頂部右角、底部左角兩層裁切重組，適配手機直向版面，保留魚群、海草與水波。
- aquaculture_fish_favicon_v1.png：網站魚圖標，用於 App 識別、首頁與魚種入口。
- watercolor_chat.png：網站知識問答圖示。
- watercolor_knowledge.png：網站小知識圖示，用於收藏與來源。
- watercolor_history.png：網站紀錄圖示，用於問答紀錄與包含紀錄入口的「我的」。

返回、展開、警告、勾選、刪除與登出等輔助操作保留簡單線條符號。圖示旁保留文字標籤，避免僅靠圖形判斷。

本次只以 CSS 調整構圖、透明度與底色，沒有生成或改寫 PNG。正式 App 拆分 repository 時應帶入這些素材與來源說明。
