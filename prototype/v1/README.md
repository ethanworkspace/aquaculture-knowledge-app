# 養殖知識 App v1 畫面原型

日期：2026-11-23。這是 Android／iPhone 共用操作流程的互動式設計原型，不是 APK／IPA，也未連接正式 API。

名稱沿用網站「養殖漁業知識平台」。背景與主要圖示共用網站原始素材；手機背景由 CSS 重新構圖為直向，搭配淡藍底與半透明內容區。素材對應見 `assets/README.md`，預覽圖為 `preview-website-theme.jpg`。

開啟 `index.html` 即可操作，無須安裝套件、無外部資源、無網路請求。可由專案根目錄執行 `python -m http.server 8877 --bind 127.0.0.1 --directory prototype/v1`，瀏覽 `http://127.0.0.1:8877`。

## 可檢視的流程

- 示範登入 → 首頁 → 選魚種／常見問題 → 提問 → 等待 → 回答 → 來源。
- 收藏回答 → 編輯個人筆記 → 搜尋收藏 → 取消收藏。
- 我的 → 問答紀錄 → 原回答；回報問題、服務狀態、清除示範資料、登出。
- 原型控制列切換正常、部分資訊、證據不足、驗證失敗、服務離線、服務忙碌及任務失敗。
- 320px 起的響應式介面；所有示範內容、來源名稱與定位均明示為設計占位，非研究答案或正式來源。

資料僅存在目前分頁記憶體，重新整理會重設。登入、刪除、回報與收藏只改變示範狀態，不代表已有正式帳號、API、持久化或多人隔離。

## 對應與差異

現有 API 見 `../../docs/api/EXISTING_API.md`。問答使用未來入口對接現有 `/v1/jobs`；回答對應 result，來源對應 question_payload.top5 與 bootstrap.sources。

原型的收藏、個人筆記、登入、回報、刪除及個人紀錄是新增 App 契約的設計，不能直接等同現有共用 `/v1/notes` 與 `/v1/history`。忙碌不顯示排隊順位；等待為本地模擬，不宣稱真實檢索階段進度。

本原型刻意不收真實帳密、不載入原始文件／圖片、不傳送 API 金鑰、不更改現有網站與模型。
