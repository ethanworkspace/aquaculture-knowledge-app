## 發現與修正

1. **等待截止時誤顯示未完成**：最後一次輪詢已收到 DONE，原本仍顯示「仍在處理中」。已修正為先處理最後回應，再判定是否超時。新增案例先重現失敗，修正後通過。
2. **來源定位顯示內部 JSON**：原頁面顯示 document_id、bbox、element_id 等資料，使摘錄難以閱讀。入口現將實際定位轉為「文件第 3 頁」等可讀資訊；新增測試並已部署，安裝版再提問後確認修正有效。

## 自動化與真實服務檢查

- Flutter format／analyze 通過，15 項一般測試通過；2 項真實推論測試預設跳過，另行啟用後各自通過。
- 真實正向問題取得 M2 回答與來源。原生 APK 另完成兩筆問答，其中一筆含斷線復原。
- 範圍外問題實際回傳 INSUFFICIENT_EVIDENCE、SYSTEM_GUIDANCE，引用為零；未將系統資訊缺口提示冒充模型成功回答。
- 後端入口 8 項測試通過；原有網站 API 的授權、手機登入／撤銷與 Origin 限制回歸通過。
- 已部署入口與 repo 程式一致。摘要不含存取碼、token、使用者資料或來源全文。
